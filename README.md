# Thievn's Den

Personal dark-themed site for thievnsden.com.

## Stack

- Next.js (App Router)
- Tailwind CSS
- TypeScript

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy on Vercel

1. Import this repo in Vercel.
2. Deploy.
3. Point your IONOS domain to the Vercel project.

## Features in this v1

- 18+ age gate (localStorage)
- Dark cohesive theme
- Home, Thoughts, Loot, Playground (Roast Me mock), Gaming, About, Join
- Responsive layout
- Subtle tone matching the brand

More content and real integrations can be added later.
